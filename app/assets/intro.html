Dónde desarrollar

Edita los archivos en tu IDE habitual. El volumen Docker ./app:/app sincroniza en caliente al guardar sin necesidad de reiniciar el contenedor.

Docker

Todas estas librerías ya están preinstaladas dentro de la imagen del contenedor. Si ejecutas la aplicación con Docker no requieres instalar nada.

Entorno local

Las librerías de Python no se copian manualmente a carpetas: se instalan en el entorno con pip. Descarga los requisitos o ejecuta en tu terminal: pip install -r requirements.txt

03 · Código

Estructura del proyecto y permisos

EURICHALLENGE / Directorio raíz
app / Directorio principal de trabajo
app.py Editable
Interfaz de usuario y flujo de sesión
Qué meter (Entradas)

Controles interactivos de Streamlit, selectores de articulación y ejercicio, configuración de umbrales articulares y alertas en pantalla.

Qué saca (Salidas)

Panel web en tiempo real, renderizado de gráficos de evolución angular, conteo de repeticiones y feedback visual para el usuario.

utils.py Editable
Visión artificial y lógica biomecánica
Qué meter (Entradas)

Extracción de landmarks con MediaPipe Pose sobre los frames de vídeo, cálculo trigonométrico de ángulos articulares y detección de transiciones de movimiento.

Qué saca (Salidas)

Frame de cámara con el esqueleto dibujado y un diccionario estructurado de métricas (ángulos instantáneos, rango de movimiento y estado de la postura).

assets / No tocar
Motor estético y recursos del sistema
estilos.css No tocar Hoja de estilos global, layout responsive e identidad gráfica del reto.
fondo.glsl No tocar Shader WebGL de neblina dinámica, oleaje y grano procedural fino.
intro.js No tocar Controlador de scroll cinemático, render loop y sincronización de WebRTC.
intro.html No tocar Estructura semántica del tutorial, navegación y paneles interactivos.
sonido.js No tocar Sintetizador Web Audio API para el efecto acústico de encendido.
eurielec.png / elgato.png No tocar Logotipos vectorizados e imagen de marca de la organización y patrocinio.

La estética de la app web no se debe tocar para garantizar la estabilidad del shader WebGL, la sincronización de vídeo y la identidad visual del reto.
